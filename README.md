# Finikwig — сайт-портфолио мастера по укладке париков

**Finikwig** — персональный сайт-портфолио мастера по укладке париков. На сайте представлены примеры работ и косплей-образы, прайс-лист на услуги и способы связи для оформления заказа.

## Возможности

- **Главная секция** с краткой информацией о мастере.
- **Интерактивная карточка** с изображениями, которая переворачивается при нажатии.
- **Портфолио работ** и галерея косплей-образов.
- **Прайс-лист** с основными услугами и начальными ценами.
- **Связь с мастером** через Telegram и VK.
- **Выпадающее меню заказа** с вариантами связи.
- **Светлая и тёмная темы** оформления.
- **Анимации появления** элементов при прокрутке.
- **Кнопка возврата наверх** с плавной прокруткой.
- **Адаптивная сетка** карточек и мобильная компоновка.

## Технологии

- **HTML5** — структура и содержимое страниц.
- **CSS3** — оформление, адаптивная компоновка, анимации и темы.
- **JavaScript** — интерактивные элементы сайта.
- **Google Fonts** — шрифты Comfortaa и Montserrat.

## Запуск проекта

Это статический сайт — установка зависимостей не требуется.

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что файлы `index.html`, `style.css` и `script.js` находятся в одной папке.
3. Добавьте папку `img/` с изображениями, используемыми на сайте.
4. Откройте `index.html` в браузере.

Для разработки можно открыть папку проекта в любом редакторе кода, например Visual Studio Code.

## Публикация через GitHub Pages

1. Загрузите файлы проекта в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите публикацию из ветки (**Deploy from a branch**).
4. Выберите основную ветку репозитория (например, `main`) и папку `/(root)`.
5. Нажмите **Save** и дождитесь публикации.
6. После завершения GitHub Pages покажет ссылку на сайт в настройках Pages.
